# 벤치 구성과 HAPS 환산

설정 파일은 [`config/bench.json`](../config/bench.json)입니다. 분석(analytical) 갈래와 실측(empirical) 갈래가 모두 이 파일을 씁니다.

## 광학 배치 (2026-10-13 사진 기준)

```
광원 → F230APC → GBE10-C (10× 확장, 레일 위) ─ 30 cm ─ 수신 확장기 역방향 (10× 축소)
     → MR-15-30 FSM → CCM1-4ER/M + BS021 (30:70) → PSD (약 20 cm)  /  PDA015C2 (약 20 cm)
                                                      ↑ 위치 센서         ↑ 통신 검출기 → USRP-2944R
```

- **송신부 전체가 레일 위에서 광축에 수직(수평)으로 평행이동합니다.** 이것이 교란입니다.
- **수신부에는 집속 렌즈가 없습니다.** CCM1-4ER/M은 빔 분할 큐브 마운트입니다. PSD와 PDA는 빔의 **위치**를 직접 봅니다(구성 (b), 직접 위치 감지).
- 레일이 FSM 한계(±4 mm)를 넘으면 수신부 짐벌로 자유도를 추가할 계획입니다. 지금 모델에는 없고, 20 Hz 구동기 민감도 실험으로만 다룹니다.

## 동작 원리

1. 송신부가 Δ만큼 움직이면 빔 방향은 그대로이고, 수신 축소기 뒤에서 위치만 `Δ/10` 이동합니다.
2. PSD가 그 이동을 봅니다.
3. FSM이 기울어져 FSM–검출기 거리 `Λ_P ≈ 0.2 m`를 지렛대로 빔을 중앙에 되돌립니다. 필요한 기계각은 `θ_x = Δ / (2 · 10 · 0.2 m)`입니다(광학 이득 2).

FSM 기계각 1 µrad당 검출기면 이동은 0.4 µm입니다. 이는 PDF 수신기(렌즈 f = 0.2 m)와 같은 값입니다. 따라서 **벤치 검출기면 잔차 = HAPS 수신기 초점면 잔차**로 볼 수 있고, 통신 지표를 HAPS 등가로 계산하는 근거가 됩니다.

## HAPS 환산

FSM 각도가 같아지는 조건으로 환산합니다. PDF의 `θ = α / (2·0.1)`과 벤치의 `θ = Δ / (2·10·0.2 m)`를 같게 놓으면 **Δ = 20 m × α**입니다.

| HAPS / PDF | 벤치 레일 |
|---|---|
| 수신 입구 도래각 α | Δ = 20 m × α (5 µrad → 100 µm, PDF Table I 송신 각도 표준편차) |
| 20 km에서 HAPS 횡변위 X | Δ = X / 1000 |
| HAPS 횡속도 1–5 m/s / 6–14 m/s | 레일 1–5 mm/s / 6–14 mm/s |
| FSM 한계 ±1 mrad(기계각) | ±4 mm (그 이상은 수신부 짐벌) |
| 구조 진동 6–18 Hz, 60–200 µrad | FSM 명령에 소프트웨어로 주입. 제어기에는 숨김 |

## 장비 모델

| 장비 | 모델에 넣은 값 | 근거 |
|---|---|---|
| MR-15-30 FSM | 폐루프 300/400 Hz, ζ = 0.7, 지터 22 µrad, 정적 오프셋 40 µrad | 데이터시트, 지터는 가정 |
| MR-E-3 드라이버 | 명령 주기 2 ms, USB 지연 1 ms | 가정 |
| CONEX-PSD | 50 Hz, 질의 후 10 ms 캡처, 20 ms에 전달, 175 Hz 아날로그 필터, 12 bit, 잡음 5 µm | 매뉴얼, 캡처 시각은 가정 |
| PDA015C2 | 반경 75 µm, 벤치 빔 반경 0.55 mm | 데이터시트, 빔 반경은 추정 |
| 레일 | 이동 ±4 mm, 20 mm/s, 0.2 m/s² | 스테이지 미확정, 가정 |
| USRP-2944R | RF 송수신만 담당(EVM/BER 측정) | — |

## 교란군

| 이름 | 내용 | 실현 방법 |
|---|---|---|
| station | 드리프트 + 0.1–0.5 Hz 흔들림 + 0.5–5 Hz 지터 | 레일 |
| sweep | 1–5 mm/s 등속 왕복 + 지터 | 레일 |
| fast_jitter | station + 2–10 Hz 지터 | 레일(가속도 한계로 지터 진폭이 작음) |
| fast_sweep | 6–14 mm/s 왕복(HAPS 6–14 m/s) + 지터 | 레일 |
| vibration | station + 6–18 Hz 구조 진동 1–2개 | 레일 + FSM 명령 주입 |
| acquisition | 2 mm 오프셋에서 시작하는 획득 | 레일 정지 후 제어 시작 |

모든 레일 프로파일이 스테이지 한계를 지키는지 [`tests/test_bench.py`](../tests/test_bench.py)에서 확인합니다. 느린 성분은 2 Hz에서 대역을 제한했습니다.

## 가정과 벤치에서 측정할 것

결과에 영향이 큰 순서입니다. 전체 목록은 `config/bench.json`의 `assumptions`에 있습니다.

1. **MR-15-30 실제 폐루프 지터:** 잔차 하한을 정합니다. 22 µrad 대신 5 µrad이면 위치 유지에서 PID 대비 이득이 7%에서 23%로 커집니다(분석 갈래 민감도 실험).
2. **레일 스테이지:** 최대 속도, 가속도, 요(yaw) 흔들림. 요 10 µrad만으로 검출기에서 약 20 µm가 추가됩니다.
3. **축소기 방향:** FSM 앞 빔 지름이 약 0.9 mm인지 확인합니다(9 mm이면 환산이 10배 달라짐).
4. **FSM–PSD, FSM–PDA 경로 길이와 검출기 위치의 빔 반경**
5. **CONEX-PSD 캡처 시각, MR-E-3 USB 지연:** 캡처 시각이 5/15 ms로 틀려도 결과는 크게 변하지 않습니다(민감도 실험).

측정한 값은 `config/bench.json`에 반영하고 분석 갈래를 다시 실행합니다.
