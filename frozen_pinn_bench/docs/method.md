# 방법: Frozen-PINN 지향 제어

원고 [`docs/paper/main.tex`](paper/main.tex) Section III을 코드와 대응시켜 정리한 문서입니다. 기호는 원고와 같습니다.

## 문제

- **센서:** PSD(CONEX-PSD)가 50 Hz로 빔 위치 `y_k`를 줍니다. 각 프레임은 질의 후 약 10 ms에 캡처되고, 다음 질의 때 전달됩니다. 따라서 제어기가 받는 정보는 항상 한 프레임 이상 늦습니다.
- **구동기:** FSM(MR-15-30)은 2 ms마다 명령 `u_m`을 받고, 1 ms 지연 후 2차 폐루프로 응답합니다.

  `θ̈ + 2ζω θ̇ + ω² θ = ω² u`  (ω = 2π·300/400 Hz, ζ = 0.7)
- **목표 (P1):** 통신 검출기에서 스폿 오프셋 `s_D = J_F θ + d − p_tar`의 기대 제곱을 최소화합니다. 여기서 `J_F = Λ_P C_F`이고, `d`는 교란(송신부 평행이동, 진동, 대기 등)입니다.
- **필요 없는 것:** 대기 굴절률 Δn과 송신부 상태입니다. 제어기는 이를 알 필요가 없고, 교란은 PSD 프레임을 통해서만 들어옵니다.

PID는 늦은 프레임에 반응하므로 교란을 따라가지 못합니다. 제안 방법은 지연 너머의 교란을 예측하고, FSM 동역학을 만족하는 명령을 한 번에 계산합니다. 두 단계 모두 **Frozen-PINN**입니다. 즉 tanh 특징을 한 번 샘플링해 고정하고, 출력은 선형 최소제곱 한 번으로 구합니다.

## 1. 의사 개루프(POL) 재구성 — `PredictiveController.on_frame`

폐루프 PSD 프레임에서 제어기 자신의 보정을 빼서 교란 샘플을 얻습니다.

`d̂_k = y_k − J_F (h_P * θ̂)(t_k^c)`

- `θ̂`: 지금까지 낸 명령에 대한 공칭 FSM 모델의 응답(`NominalPlant`)
- `h_P`: PSD 아날로그 필터(175 Hz)
- `t_k^c`: 캡처 시각

`d̂_k`는 제어기와 무관하므로, FSM을 고정하고 기록한 개루프 데이터로 학습한 예측기를 어떤 제어기에도 쓸 수 있습니다. 준정적 극한에서는 보정 오차 `C_F^true = (I+E)C_F`가 지향 오차로 이어지지 않습니다(같은 `J_F`로 역산하므로 상쇄).

## 2. Frozen-PINN 교란 예측기 — `pat/predictor.py: ContextModel`

- **입력:** 최근 N = 12 샘플을 최신값 기준 차분으로 넣고, 최신값도 함께 넣습니다(`z_k ∈ R^{2N}`).
- **출력:** 다음 H = 4 프레임의 증분 `d̂_{k+h} − d̂_k`입니다.
- **레이블:** 미래 PSD 프레임이므로 별도 센서가 필요 없습니다. 벤치 로그로 같은 학습을 반복할 수 있습니다.
- **은닉층:** M = 512개 특징 `φ_m(z) = tanh(w_mᵀ z + b_m)`.
  - SWIM 방식으로 학습 입력 쌍 (z_i, z_j)를 출력 변화율 `‖v_j − v_i‖/‖z_j − z_i‖`에 비례하는 확률로 뽑습니다.
  - `w_m = 2s(z_j − z_i)/‖z_j − z_i‖²`, `b_m = −½ w_mᵀ(z_i + z_j)`, `s = artanh(½)`
  - 한 번 뽑은 뒤 고정합니다. 경사하강은 쓰지 않습니다.
- **출력층:** `ψ(z) = [z, φ(z), 1]`에 대한 릿지 최소제곱 `B₀ = (ΨᵀΨ + λI′)⁻¹ ΨᵀV`. λ는 검증 세트로 고릅니다.
- **선형 특수해:** 원입력 z가 ψ에 포함되므로 M = 0이면 선형 AR 예측기가 됩니다. ablation으로 보고합니다.
- **0차 웜스타트:** 이력이 N개 차기 전에는 최신 샘플을 유지합니다. 첫 프레임부터 측정 오프셋을 한 번에 보정합니다.

## 3. 일회 온라인 재적합 — `OnlineReadout`

N_r = 50 프레임마다 현재 운용의 최근 W 프레임(검증으로 선택)으로 출력층만 다시 풉니다. 이때 오프라인 해 쪽으로 당깁니다.

`B = (Ψ_WᵀΨ_W + λ_o I)⁻¹ (Ψ_WᵀV_W + λ_o B₀)`

은닉층은 고정이므로 재적합 한 번은 Q × Q 선형 풀이 하나입니다(Q = 2N + M + 1).

## 4. 보간 — `PredictiveController._interpolate`

`{d̂_{k−2}, …, d̂_k, d̂_{k+1}, …, d̂_{k+H}}`를 Lanczos 커널 `κ(x) = sinc(x) sinc(x/3)`로 보간해 임의 시각의 `d̂(t)`를 얻습니다. PSD 필터 지연 τ_P를 반영합니다.

## 5. 물리 잔차 명령층(시간축 Frozen-PINN) — `pat/command_layer.py`

새 명령이 거울에 닿는 시각 `t_m^a = t_m + τ_u`부터 `τ ∈ [0, T_h]` 동안(T_h = n_h T_u), 각 축의 FSM 각도를 다음과 같이 둡니다.

`θ_a(τ) = θ_{0,a} + θ̇_{0,a} τ + τ² Σ_j c_{a,j} tanh(α_j τ/T_h + β_j)`

- 초기 각도와 각속도는 형태상 정확히 만족하므로, 초기조건 손실이 필요 없습니다.
- `(θ₀, θ̇₀)`는 직전 명령으로 공칭 모델을 정확히 전파해 얻습니다.

**최소화 대상**(N_τ = 48 collocation 점):
- FSM ODE 잔차: `r^ode = (θ̈ + 2ζω θ̇)/ω² + θ − u`, 가중 μ = 1e4
- (P1) 지향 잔차: `r^pt = Λ_P⁻¹ (J_F θ(τ_i) + d̂(t_m^a + τ_i) − p_tar)`, 처음 n_p 명령 주기만 평가
- 명령 변화 패널티: `ρ‖u − u_{m−1}‖²`, ρ = 1e-4

모든 잔차가 `(c, u)`와 알려진 벡터 `b_m = [θ₀, θ̇₀, u_{m−1}, p_tar, d̂(τ_1..τ_N)]`에 대해 affine입니다. 따라서 해는 `u_m = Π[K_u b_m]`이고, `K_u`는 한 번만 계산합니다. 명령 한 번은 행렬-벡터 곱 하나입니다. 지평 `(n_h, n_p)`는 검증으로 고르며, 구동기가 바뀌면(`fsm.*` 변경) 다시 고릅니다.

- 구동기가 순수 지연이면 이 해는 리드 근사 `u = J_F⁻¹(p_tar − d̂(t_m + τ_e))`로 줄어듭니다. 여기서 `τ_e = τ_u + T_u/2 + 2ζ/ω`입니다.
- MR-15-30처럼 빠른 FSM에서는 두 방법이 거의 같습니다.
- 구동기 대역이 명령 주기에 가까워지면(짐벌급) 물리 잔차가 근사 오차를 되찾습니다.

## 6. 기준 PID — `PIDController`

PSD 오차 `e_k = J_F⁻¹(p_tar − y_k)`에 대한 위치 PID입니다.
- 프레임마다 갱신하고 프레임 사이에는 유지합니다.
- 미분 항에는 1차 필터를 쓰고, 제약에서는 조건부 적분을 합니다.
- 이득은 교란군마다 그 교란군의 학습 seed로 폐루프 격자 탐색해 다시 튜닝합니다(PID에 유리한 조건).
- Frozen-PINN은 세 교란군을 섞은 학습 세트로 한 번만 학습합니다.

## 7. HAPS 등가 통신 지표 — `pat/comm.py`

벤치 검출기면 잔차를 HAPS 수신기 초점면 오프셋으로 옮겨(지렛대 = f = 0.2 m), 초점면 포착 함수 `η_D(s)`로 정규화 전력을 구합니다. 검출기 반경은 75 µm와 25 µm 두 가지입니다.

| 지표 | 식 |
|---|---|
| 순시 SNR | `γ(t) = γ_al η̄(t)²` (IM/DD, 신호와 무관한 잡음) |
| BER | `BER_M(γ) = 4/log₂M (1 − 1/√M) Q(√(3γ/(M−1)))` (Gray 정사각 M-QAM) |
| outage | `Pr{γ(t) < γ_64^th}`. γ_64^th는 BER 3.8e-3(HD-FEC)이 되는 SNR = 21.1 dB |
| 데이터율 | `R_s ρ_p E[max{log₂M : γ(t) ≥ γ_M^th}]`, M ∈ {4, 16, 64, 256}, R_s = 10 Mbaud, ρ_p = 0.824 |

- 동작점은 `γ_al = γ_64^th + 3 dB = 24.1 dB`입니다.
- 그림용 심볼 시뮬레이션(`simulate_symbols`)은 0.5 ms마다 파일럿 블록으로 이득을 추정합니다.
