# 분석 갈래 결과: 벤치 모델 + HAPS 등가 링크

- 실행: `results/analytical/main/`
- 수치 표: [`RESULTS.md`](../results/analytical/main/RESULTS.md) (summary.json에서 자동 생성)
- 그림: [`figures/`](../results/analytical/main/figures/) (설명은 `FIGURES.md`)

**모든 값은 벤치 모델 시뮬레이션입니다. 하드웨어 측정이 아닙니다.** 실측은 [실측 갈래](empirical_protocol.md)로 얻습니다.

## 설정

- **시험 세트:** 교란군마다 학습에 쓰지 않은 16 에피소드 × 20 s(처음 2 s 제외)입니다.
- **잔차:** 0.5 ms 간격의 검출기면 오프셋이며, HAPS 수신기 초점면 오프셋과 같습니다. PDF 입구 도래각[µrad]은 잔차[µm]의 1/2입니다.
- **Frozen-PINN:** station, fast_sweep, vibration을 섞은 개루프 기록으로 한 번만 학습합니다.
- **PID:** 시험 교란군마다 그 교란군의 학습 seed로 다시 튜닝합니다(PID에 유리한 조건).
- **정보:** 모든 제어기가 같은 PSD 프레임, 같은 보정값, 같은 목표점을 받습니다. Oracle은 실제 교란을 아는 하한(FSM 지터 하한)입니다.

## 지향 (A03, A04, A05, A06)

| RMS 잔차 [µm] | 위치 유지 | 왕복 1–5 m/s | 빠른 지터 | **빠른 이동 6–14 m/s** | **진동 주입** |
|---|---|---|---|---|---|
| PID(교란군별 튜닝) | 16.3 | 17.3 | 15.6 | 24.2 | 29.9 |
| **Frozen-PINN** | 15.1 | 14.9 | 14.7 | **14.9 (−38%)** | **17.8 (−40%)** |
| Oracle(지터 하한) | 11.4 | 11.4 | 11.6 | 11.4 | 11.6 |

- **느린 레일 교란에서는 차이가 작습니다(−6~−14%).** 레일 가속도 한계(0.2 m/s²) 때문에 교란이 PID 대역 안에 있고, 잔차 대부분은 PSD로 볼 수 없는 FSM 지터(하한 11.4 µm)입니다.
- **교란이 빨라질수록 차이가 커집니다.** PID 잔차는 HAPS 속도에 따라 17.7 → 27.9 µm로 커집니다. Frozen-PINN은 14.8–15.2 µm로 거의 일정합니다(A04). PID는 최소 한 프레임(20 ms) 늦은 정보에 반응하고, Frozen-PINN은 그 지연 너머를 예측하기 때문입니다.
- **스펙트럼(A05):** PID에는 저주파 추종 지연과 6–18 Hz 진동선이 남습니다. Frozen-PINN은 25 Hz 이하에서 이 성분을 지터 하한 근처까지 줄입니다.

## 통신 (A07, A08, A09, A10, A11, A12)

**동작점:** 정렬 SNR 24.1 dB(64-QAM FEC 임계값 + 3 dB)

| 시나리오 | 25 µm outage | 25 µm 데이터율 [Mb/s] | 75 µm outage | 75 µm 64-QAM BER |
|---|---|---|---|---|
| 위치 유지 | 32.7 → 27.9% | 42.7 → 44.0 | 0 → 0 | 1.3e-4 → 1.3e-4 |
| **빠른 이동** | **60.1 → 27.2%** | **33.3 → 44.2 (+33%)** | 0.09 → 0% | 1.6e-4 → 1.3e-4 |
| **진동 주입** | **70.4 → 38.3%** | **27.6 → 41.1 (+49%)** | **1.94 → 0.04%** | **1.7e-3 → 1.4e-4** |

- **75 µm 검출기(PDA015C2급):** 포착 함수가 ±40 µm까지 평평합니다(A01). 그래서 진동 주입 때만 차이가 납니다.
- **25 µm 고속 검출기:** 수 µm부터 전력이 줄어, 잔차 차이가 그대로 outage와 데이터율 차이가 됩니다.
- **획득(A10):** 2 mm 오프셋에서 시작하면 Frozen-PINN은 첫 PSD 프레임(20 ms) 직후 한 번에 맞춥니다(0차 웜스타트 + 지렛대 역산). PID는 40–70 ms에 맞춥니다.

## 구성 요소별 기여 (ablation)

| RMS 잔차 [µm] | 위치 유지 | 빠른 이동 | 진동 주입 |
|---|---|---|---|
| Frozen-PINN(전체) | 15.1 | 14.9 | 17.8 |
| 온라인 재적합 제거 | 15.8 | 15.5 | 25.4 |
| 물리 잔차 명령층 제거(리드 근사) | 15.1 | 14.9 | 17.8 |
| 선형 예측기(M = 0) + 재적합 | 14.9 | 15.1 | **16.8** |

- **맥락 적응(일회 온라인 재적합)이 가장 큰 기여를 합니다.** 진동 주입에서 25.4 → 17.8 µm입니다. 진동 주파수와 진폭이 에피소드마다 달라, 현재 운용의 최근 프레임으로 출력층을 다시 푸는 것이 효과적입니다.
- **비선형 은닉층(M = 512)은 선형 대비 일관된 이득이 없습니다.** 진동 주입에서는 선형이 더 좋습니다(16.8 대 17.8 µm). 원고에는 ablation으로 그대로 보고합니다.
- **물리 잔차 명령층은 MR-15-30에서는 근사와 같습니다**(위치 유지 15.10 대 15.14 µm). FSM(300/400 Hz)이 명령 주기(2 ms)보다 훨씬 빨라, 리드 근사가 이미 정확하기 때문입니다.

## 민감도

| 조건 | PID | Frozen-PINN | Oracle |
|---|---|---|---|
| 기준(위치 유지) | 16.3 | 15.1 | 11.4 |
| FSM 지터 5 µrad(가정 22 µrad) | 11.4 | 8.8 (−23%) | 4.1 |
| PSD 실제 캡처 15 ms / 5 ms(가정 10 ms) | 15.6 / 17.1 | 14.8 / 15.8 | 11.4 |
| 1 m/s² 스테이지, 왕복 / 빠른 지터 | 17.6 / 16.9 | 15.6 / 16.5 | 11.4 / 11.6 |
| **20 Hz 짐벌급 구동기** | 18.0 | **16.1** (리드 근사 17.1) | 11.4 |

- **FSM 지터가 작을수록 상대 이득이 커집니다.** 실제 지터 측정이 중요한 이유입니다.
- **구동기가 느려지면 물리 잔차 명령층이 필요해집니다.** 20 Hz에서 리드 근사보다 5.4% 낮습니다(17.1 → 16.1 µm). 계획한 수신부 짐벌(FSM 한계를 넘는 대동작)에 적용할 부분입니다.
- PSD 캡처 시각을 ±5 ms 틀려도 결과가 크게 변하지 않습니다.

## 해석의 범위

- **통신 지표는 HAPS 등가값입니다.** 벤치 PDA는 렌즈 없는 0.55 mm 빔을 받아 수십 µm 잔차에 둔감합니다(A01 점선). USRP로 직접 잰 벤치 BER에는 제어기 차이가 거의 나오지 않을 것으로 예상합니다.
- **SNR 가정:** SNR ∝ 전력²(IM/DD, 신호와 무관한 잡음)입니다. 동작점 여유 3 dB, 10 Mbaud는 가정입니다.
- **진동은 레일로 만들 수 없습니다.** FSM 명령에 소프트웨어로 주입하고 제어기에는 숨깁니다. 벤치에서도 같은 방식으로 재현할 수 있습니다.
- **교란군은 HAPS 환산 시험 입력입니다.** 실측 HAPS 데이터가 아닙니다.
